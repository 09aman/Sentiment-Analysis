# Sentiment Analysis

A machine-learning web application built with **Streamlit** that predicts the emotion expressed in user-provided text.

The application uses a trained **CountVectorizer + Logistic Regression** pipeline and displays the predicted emotion along with class probabilities when the model supports probability estimates.

## Features

- Enter a sentence, product review, or other text.
- Predict the emotion associated with the text.
- Display the predicted emotion.
- Display probabilities for each emotion (when supported by the model).
- Simple web interface built with Streamlit.

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- CountVectorizer
- Logistic Regression
- Joblib

## Setup and Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/Sentiment-Analysis.git
   cd Sentiment-Analysis
   ```

2. (Recommended) Create and activate a virtual environment:

   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   **Windows**
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL shown in your terminal (usually `http://localhost:8501`).

## Model Files

The application expects these files in the same directory as `app.py`:

- `sentiment_analysis_model.pkl` — the trained machine-learning pipeline.
- `Emotions.pkl` — the mapping between model class labels and emotion names.

These files are not generated by the application. Add the trained files that correspond to your model.

## Notes

- The model's predictions depend on the data and labels used during training.
- Probability scores are model estimates, not guarantees that a prediction is correct.
- Only load `.pkl` files from sources you trust because pickle files can execute code when loaded.
